# ADR-0001: Primer ADR - Definición de ADR

## Decisión

Este es el primer Architecture Decision Record (ADR) del proyecto. Un ADR documenta una decisión oficial del proyecto.

## Razón

Tener un registro explícito de las decisiones arquitectónicas evita que se pierdan en el tiempo y obliga a justificar cada cambio importante.

## Consecuencias

- Cada decisión clave se documenta con su contexto, opciones y justificación.
- No se puede modificar una decisión sin un nuevo ADR que lo justifique.
- La carpeta `ADR-SYSTUTOR` es la única fuente de verdad sobre acuerdos arquitectónicos.

---

**No la rompas sin justificarlo.**
