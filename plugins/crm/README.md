# CRM Plugin

Plugin de clientes para SYSTUTOR OSS.

Incluye:

- clientes con validacion fiscal multi-pais;
- direcciones con geolocalizacion;
- contactos adicionales;
- catalogos de tipos de documento y formas de pago;
- geografia jerarquica;
- integracion con `logistics` via `customer_id` real.

La guia de mantenimiento y extension vive en `docs/modifying-crm.md`.
