# productos

Plugin de catalogo maestro de productos.

Alcance de esta primera implementacion:

- catalogos base por tenant;
- producto maestro;
- codigos de barras;
- precios y costos historificados;
- configuracion ADR;
- impuestos del producto;
- media local preparada para evolucion a R2;
- promociones simples.

No incluye stock ni migracion profunda de logistics en esta fase.
